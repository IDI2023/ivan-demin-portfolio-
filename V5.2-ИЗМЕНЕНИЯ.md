## 4. Просмотр на мобильных устройствах

- В `site.js` событие клика перехватывается только **после успешного открытия** модального окна; если оно недоступно, сохраняется обычная ссылка на MP4 или первый слайд.
- В диалоге видео есть «Открыть видео отдельно» и понятное сообщение при ошибке плеера.
- В диалоге Buldak есть «Открыть слайд отдельно»; листание пяти изображений по кнопкам и клавиатуре сохранено.
- `make_preview.py` больше **не встраивает видео через base64** в гигантский HTML. Предпросмотр содержит изображения и внешний доступ к MP4 в соседней папке `assets/`.
- Workflow GitHub Pages дополнен копированием папки неизменённых исходников, чтобы ссылки «Без обрезки» работали и после публикации.
