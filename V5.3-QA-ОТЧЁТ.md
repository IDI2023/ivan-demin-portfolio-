### Доказательства и клавиатура

- Все публичные `proof-modal` имеют один пункт верхней панели — «Закрыть»; ссылки «Полный размер» и «Без обрезки» отсутствуют.
- Escape закрывает просмотрщик, фокус возвращается на кнопку статистики.
- Tab и Shift+Tab внутри открытого просмотрщика остаются на единственном доступном элементе управления.
- Проверен переход: таблица опроса → оригинал 1 → таблица → оригинал 2 → таблица → кнопка «Посмотреть результаты опроса». Возврат фокуса проверен.
- Без JavaScript проверены CSS `:target`-просмотр доказательства и раскрытие пяти резервных ссылок Buldak.

### Видео и карусель

- Все пять кнопок видеоработ раменной открывают соответствующее нативное диалоговое окно в проверенной браузерной среде; источник видео назначается нужным MP4, после закрытия сбрасывается.
- Карусель открывается, перелистываются все пять слайдов, Escape закрывает окно.
- Для восьми MP4 проверено наличие H.264-видеодорожек и AAC-аудиодорожек через FFprobe.
- Все видеофайлы сохранены побайтово без изменений. **Фактическое воспроизведение со звуком в Safari на реальном телефоне не проверялось.**

### Сборка и редактируемость

- Штатный запуск `python build.py`: успешно.
- Штатный запуск `python make_preview.py`: успешно (предпросмотр ~9,65 MiB без встроенных видео).
- Временное редактирование метрики в JSON и сборка в отдельной копии: успешно; оригинальный JSON не менялся.
- Все пути к доказательствам проверены при сборке.
- Исполняемый JavaScript прошёл `node --check`.
- 65 исходных и используемых медиафайлов сравнивались побайтово с архивом V5.2.

## Что не проверялось

- **Реальный iPhone Safari** и Android Chrome на физических устройствах.
- Воспроизведение MP4 через реальный опубликованный HTTPS-сайт; в тестовой `set_content`-среде относительные MP4 недоступны для сетевого воспроизведения, проверена только инициализация диалога и связи с файлами.
- Полное соответствие WCAG 2.2 AA (для него необходим также ручной аудит и проверка вспомогательных технологий).
- Фактическая публикация на GitHub Pages, внешняя доступность URL и автоматические метрики Core Web Vitals (LCP, INP, CLS).

Эти ограничения **не считаются успешно пройденными тестами**. Рекомендуется окончательно проверить сайт после публикации в Safari на iPhone.
