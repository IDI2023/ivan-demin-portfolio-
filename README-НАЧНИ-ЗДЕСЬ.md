# Иван Демин — портфолио V5.3

Это точечная доработка V5.2. **Дизайн Digital Editorial, утверждённые тексты и расположение двух кейсов не менялись.** Сайт остаётся статическим и работает без платного сервера.


## Изменения V5.3

- В шести карточках кнопки стоят непосредственно под статистикой; отдельные ссылки на пять слайдов Buldak доступны в раскрывающемся блоке **после галереи**.
- В просмотрщике доказательств остались заголовок, скриншот и кнопка закрытия; кнопки «Полный размер», «Без обрезки» и служебные подписи удалены.
- Все исходники медиа и исходные необрезанные скриншоты сохранены; подтверждённая статистика и тексты не менялись.
- Отчёт: `V5.3-QA-ОТЧЁТ.md`. Скриншоты: `previews_v5_3/`.

## Что открыть

- **`index.html`** — полноценный сайт с отдельными медиафайлами из папки `assets/`. Для надёжной проверки видео открывайте его после бесплатной публикации на GitHub Pages.
- **`Иван-Демин-ПРЕДПРОСМОТР.html`** — облегчённый предпросмотр (~15 МБ): стили, JavaScript и изображения встроены, **но видеоролики НЕ встроены**. Чтобы они работали, держите HTML в распакованной папке рядом с `assets/`. Самостоятельный файл без папки `assets/` не обеспечивает просмотр видео.
- **`previews_v5_2/`** — изображения сайта на мобильном и компьютере.
- **`V5.2-QA-ОТЧЁТ.md`** — что было проверено и что не было.
- **`V5.2-ИЗМЕНЕНИЯ.md`** — список исправлений и обрезанных скриншотов.
- **`ТАБЛИЦА-РАБОТ-И-СТАТИСТИКИ.md`** — соответствие 6 публикаций доказательствам.

### Почему iPhone может не воспроизводить видео в окне ChatGPT

Встроенный просмотр HTML-файла в приложении и обычный сайт, открытый через HTTPS в Safari, — разные среды. Видео в текущей версии находятся в отдельных MP4, поэтому после загрузки ZIP на GitHub Pages они будут запрашиваться по обычным URL. Если встроенный плеер не запускается, нажмите **«Открыть видео отдельно»** в окне ролика или используйте прямую ссылку карточки при недоступном JavaScript. Без публикации на HTTPS совместимость именно с вашим iPhone не подтверждена.

## Как редактировать контент

Все основные поля — в `data/site.json`; для визуального редактирования можно подключить бесплатный Pages CMS к GitHub. Сохранилась архитектура из V5.1.

| Поле в `data/site.json` | Что меняет |
|---|---|
| `portfolio_works` | 5 Reels/TikTok и карусель «СамаРамён»: название, метрика, видео, постер, `proof` |
| `proofs` | Подпись, публичный скриншот (`image`), ссылка на исходник (`uncropped_original`), `return_to` |
| `sama_metrics`, `sama_period_metric` | Основные показатели двух аккаунтов и 411,5 тыс. просмотров за период |
| `blesk_reels` | Два Reels «Блеска» и метрики |
| `survey_sources` | Все источники опроса, сумма и доли пересчитываются автоматически |
| `bot_media`, `bot_stats` | Скриншоты/видео VK-бота; статистика пока пуста и скрыта |

**Поменять скрин статистики:** добавьте файл в `assets/`, измените поле `image` у нужного `id` в `proofs`. `id` не меняйте, иначе кнопки потеряют привязку. Если снимок подрезан, его исходный вариант можно сохранить в `source-archive/original-proofs/`, а путь записать в `uncropped_original`.

**Поменять видео:** поместите MP4 в `assets/` и измените `video` у нужной записи. Для iPhone предпочтительно H.264/AAC, MP4 с moov в начале (faststart). Видео автоматически не воспроизводятся при загрузке страницы.

**Обновить цифры:** сначала получите подтверждение, затем синхронно обновите метрику карточки и соответствующее доказательство. **Не выдумывайте конверсию/доход VK-бота:** `bot_stats` остаётся пустым до появления подтверждения.

### Пересобрать сайт

1. После изменений в `data/site.json` выполните `python build.py` в корне проекта.
2. Откройте созданный `index.html` вместе с папкой `assets/`.
3. Не меняйте только `index.html`: он генерируется из `index.template.html` и `data/site.json`.
4. Чтобы заново создать лёгкий предпросмотр с изображениями, запустите `python make_preview.py` (`pip install beautifulsoup4` требуется только для этой необязательной операции).

## Бесплатно опубликовать в GitHub Pages

1. Создайте бесплатный аккаунт GitHub и новый репозиторий (например, `ivan-demin-portfolio`) с разрешённым Pages; для стандартного бесплатного аккаунта проще использовать публичный репозиторий.
2. Загрузите **содержимое** ZIP в корень репозитория, сохраняя `assets/`, `data/`, `source-archive/original-proofs/` и скрытую папку `.github/workflows/`. Можно воспользоваться бесплатным GitHub Desktop для загрузки папки целиком.
3. Откройте **Settings → Pages → Build and deployment → GitHub Actions**.
4. В репозитории уже есть `.github/workflows/deploy.yml`: после отправки изменений в ветку `main` он запускает `python build.py` и публикует сайт.
5. После появления ссылки GitHub Pages откройте её на iPhone в Safari, проверьте **все пять видео «СамаРамён», два Reels «Блеска», видео VK-бота и карусель Buldak**.
6. Для обновления метрик измените `data/site.json` и загрузите изменения в GitHub. При последующей публикации скрипт пересоберёт страницу.

GitHub Pages подходит для статического портфолио, обязательных платных сервисов нет. До фактической публикации нельзя гарантировать корректное воспроизведение на конкретном iPhone или реальные показатели Core Web Vitals.
